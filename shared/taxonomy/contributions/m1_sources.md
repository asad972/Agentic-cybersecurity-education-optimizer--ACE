# M1 Taxonomy Contribution Sources

## Scope and Covered Roles
This contribution defines skills and industry certifications aligned with the European Cybersecurity Skills Framework (ECSF) role profiles:
- **Cyber Incident Responder**: Intrusion detection and prevention, network security monitoring, root cause analysis, and security automation (SOAR).
- **Digital Forensics Investigator**: Malware triage, artifact analysis, and volatile memory forensics.
- **Penetration Tester**: Offensive security methodologies, credential access, privilege escalation, lateral movement, and post-exploitation techniques.

## Primary Sources
1. **ENISA European Cybersecurity Skills Framework (ECSF)**: Role profile definitions, key tasks, and associated skills.
2. **NIST SP 800-61 Rev. 2**: Computer Security Incident Handling Guide.
3. **MITRE ATT&CK**: Enterprise matrix techniques for credential access, lateral movement, and privilege escalation.
4. **SANS Institute / GIAC Roadmap**: Digital forensics and web application penetration testing certifications (GCFE, GNFA, GWAPT).
5. **OffSec, Security Blue Team & Splunk**: OSWE, OSEP, OSED, BTL1, BTL2, and Splunk Core Certified Consultant certification syllabi.
