# Web app (M4 sets up, everyone builds a dashboard)

React app with Leaflet or ECharts maps. The home page is the **Europe map** (M4): a CyberSeek-style choropleth with a metric switch (job ads, Demand, Supply, Skills Gap, education programmes, hiring companies).

M4 builds the app shell and the Europe map. Each member builds one dashboard with at least 2 graphs, and the API endpoints it uses:

| Dashboard | Member |
| --- | --- |
| Role explorer (career pathway) | M1 |
| Skills demand | M2 |
| Supply, gap and forecast | M3 |
| Threat landscape | M4 |
| Education and workforce | M5 |

Graphs per dashboard are listed in [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#serving-and-visualization).
